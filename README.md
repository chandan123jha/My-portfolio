# Chandan Jha — Premium Portfolio

A single-page personal portfolio built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Quality checks

```sh
npm run lint
npm run build
```

The source is intentionally kept readable and unminified.

## Included updates

- Premium midnight / porcelain / vermilion visual system
- Full-viewport animated hero
- Staggered entrance animations and subtle micro-interactions
- Responsive navigation and mobile menu
- Four featured projects: Alpha Dream Homes, Yellow Star, The Knowledge Key, and A.J. Towing Service
- Live links for the three confirmed project URLs
- Updated one-page resume in `public/resume.pdf`
- Responsive skills, experience, education, achievements and contact sections
- Scroll progress indicator
- Reduced-motion support
- SEO metadata and accessibility-focused structure

## A.J. Towing live URL

The A.J. Towing project is included, but its live URL was not present in the supplied portfolio project. A URL has intentionally not been invented. Add the confirmed URL in `src/data/projects.js` when available.

## Project visuals

The project cards use original CSS-built editorial previews so the portfolio does not display fake stock images or broken screenshot placeholders. Genuine screenshots can be added later if desired.

## Contact form

The contact form opens the visitor's email application. It does not submit form data to a server.
